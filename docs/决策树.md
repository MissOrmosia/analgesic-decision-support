# 决策树（状态机全路径表）· beta1.0

> 本表从 `index.html`（beta1.0）代码逐分支枚举生成，与代码一一对应。
> 记法：A = 场景，B = 年龄，R = 肾功能，N = NSAIDs 筛查，F = 禁食/口服，T = 阿片耐受。
> 🔴 = 强制会诊（不提供任何药物推荐）｜🟠 = 建议会诊（可继续，留痕）｜🟢 = 输出推荐方案

## 代号对照表（记法释义）

| 代号 | 含义 | 对应选项 / 取值 |
|:---|:---|:---|
| A | 场景（scene） | A1 = 突发痉挛疼痛；A2 = 术后疼痛；A3 = 晚期癌痛；A4 = 带状疱疹后神经痛 |
| B | 年龄（age group） | B1 = 成人（≥18 岁）；B2 = 小儿（<18 岁，需输入精确年龄） |
| R | 肾功能（renal status） | R1 = 无异常 / 未查及明显异常；R2 = 有异常 / 不确定 → 进入分层；R3 = 暂未查 |
| R 分层 | R2 的五个取值 | 正常（CLcr ≥ 90）/ 轻度（60–89）/ 中度（30–59）/ 重度（15–29）/ 极重度（<15 mL/min） |
| N | NSAIDs 筛查 | N-ulcer = 胃十二指肠溃疡；N-ibd = 炎症性肠病；N-none = 无上述疾病 |
| U | 溃疡活动度（仅 N-ulcer 时追问） | U-active = 活动性溃疡；U-history = 已愈合（有溃疡病史） |
| F | 术后口服状态（仅 A2） | F1 = 禁食期（NPO）；F2 = 已恢复口服（PO） |
| T | 阿片耐受状态（仅 A3 不能口服时追问） | T-tolerant = 已阿片耐受；T-naive = 未耐受 / 不确定 |
| 输出标记 | — | 🔴 = 强制会诊（不推荐任何药物）；🟠 = 建议会诊（可继续，留痕）；🟢 = 输出推荐方案 |

## 一、全局前置流程（所有场景共用）

```
场景选择 A → 年龄选择 B →（小儿：输入精确年龄）→ 肾功能筛查 R → 场景分支
```

**肾功能筛查 R 的三个出口：**

| 路径 | 成人 | 小儿 |
|:---|:---|:---|
| R1 正常/未查及明显异常 | 放行 | 放行 |
| R2 有异常 → 分层 | 轻/中度：🟠或警示后放行；重度/极重度：🔴 肾内科+疼痛科 | **任意层级（含轻度）：🔴 儿科+肾内科**（问题 103） |
| R3 暂未查 | 警示后可继续（留痕） | 🔴 必须完善检查，或🔴 肾内科会诊后按专科指导 |

## 二、A1 突发痉挛疼痛

| 路径 | 判定链 | 输出 |
|:---|:---|:---|
| A1→B2→年龄<2 | R 正常 → N 任意 | 🔴 儿科强制会诊 |
| A1→B2→合并溃疡/IBD | N 筛查触发边界 | 🔴 儿科+消化内科强制会诊 |
| A1→B2→2–11 岁，无禁忌 | R 正常 + N 无 | 🟢 右旋布洛芬（首选）/ 对乙酰氨基酚滴剂按体重；曲马多<12 禁用 → 🟠 儿科会诊确认 |
| A1→B2→≥12 岁，无禁忌 | 同上 | 🟢 白名单（间苯三酚/右旋布洛芬/对乙酰氨基酚，曲马多可备选）→ 🟠 儿科会诊确认 |
| A1→B1（成人）→N 无禁忌 | — | 🟢 间苯三酚 + 酮咯酸联用（问题 78）；轻度肾损/未查附加红字警示 |
| A1→B1→N 溃疡/IBD | — | 🟢 仅解痉药（避开 NSAIDs），效果不佳转专科会诊 |

## 三、A2 术后疼痛

入口：B 之后先行 N 筛查（若未做过），再选 F（禁食/口服）。

### F1 禁食期（NPO）

| 路径 | 输出 |
|:---|:---|
| →B2→触发边界（<2岁/溃疡/IBD/肾损） | 🔴 儿科+对应专科强制会诊 |
| →B2→2–11 岁，无禁忌 | 🔴 强制儿科会诊（白名单内无可用注射药） |
| →B2→≥12 岁，无禁忌 | 🟢 曲马多针（酮咯酸/吲哚美辛多次给药不推荐）→ 🟠 儿科会诊确认 |
| →B1→溃疡 | 🟢 阶梯从曲马多针起（移除 NSAIDs），🔴样式警示 |
| →B1→IBD | 🟢 同上（🟠样式警示） |
| →B1→无禁忌，中/重度肾损 | 🟢 避开 NSAIDs：曲马多 50mg q8h 起 + 芬太尼类需专科评估（问题 74/86） |
| →B1→无禁忌，其他 | 🟢 全阶梯：酮咯酸→吲哚美辛栓→曲马多→芬太尼类；轻度肾损/未查附加减量警示 |

### F2 已恢复口服（PO）

| 路径 | 输出 |
|:---|:---|
| →B2→触发边界 | 🔴 强制会诊（同上） |
| →B2→2–11 岁，无禁忌 | 🟢 对乙酰氨基酚（<6 岁禁片剂）+ 右旋布洛芬按体重；曲马多禁用 → 🟠 儿科会诊确认 |
| →B2→≥12 岁，无禁忌 | 🟢 白名单 + 曲马多可备选 → 🟠 儿科会诊确认 |
| →B1→溃疡 | 追问溃疡活动度：活动性/未明 → 🟢 避开 NSAIDs（对乙酰氨基酚+曲马多），🔴警示；已愈合 → 🟢 同上，塞来昔布须联 PPI + 消化科会诊 |
| →B1→IBD | 🟢 避开 NSAIDs + 消化内科会诊提示 |
| →B1→无禁忌，中/重度肾损 | 🟢 对乙酰氨基酚起手 + 曲马多 q8h，避开 NSAIDs |
| →B1→无禁忌，其他 | 🟢 全阶梯（酮咯酸口服→氟比洛芬酯→吲哚美辛栓→散利痛→曲马多） |

## 四、A3 晚期癌痛

| 路径 | 输出 |
|:---|:---|
| →B2（小儿） | 🔴 选完年龄直接强制会诊（儿科+疼痛科），不问精确年龄、不查肾功能（问题 69） |
| →B1→任意肾功能不全（含轻度） | 🔴 强制疼痛科+肾内科会诊（问题 92），不再问口服与否 |
| →B1→肾功能正常 → 能口服 | 建议疼痛科会诊提示 → N 筛查 → 🟢 阶梯：对乙酰氨基酚→曲马多→奥施康定；溃疡活动/IBD 时移除 NSAIDs，已愈合溃疡须 PPI |
| →B1→肾功能正常 → 不能口服 | 先问 **T 阿片耐受**（问题 72）：耐受 → 🟢 多瑞吉 ± 氟比洛芬酯（合并症时移除 NSAIDs）；未耐受/不确定 → 🔴 禁多瑞吉 + 强制疼痛科会诊指导滴定 |
| （接上）高级方案 | 常规不佳时追问 → 是 → 🟠 疼痛科会诊确认后展示（鞘内吗啡泵/神经阻滞/神经毁损） |

## 五、A4 带状疱疹后神经痛

## 六、全局约束（横切所有路径）

| 机制 | 规则 |
|:---|:---|

# 🇬🇧 English Version

# Decision Tree (Full State-Machine Path Table) · beta1.0

> Enumerated branch-by-branch from the beta1.0 `index.html`, corresponding one-to-one with the code.
> Notation: A = scene, B = age group, R = renal function, N = NSAID screening, F = NPO/PO status, T = opioid tolerance.
> 🔴 = mandatory consult (no drug recommendation) ｜ 🟠 = recommended consult (may proceed, logged) ｜ 🟢 = recommendation printed

## Code Legend (Notation Reference)

| Code | Meaning | Options / Values |
|:---|:---|:---|
| A | Scene | A1 = acute spasmodic pain; A2 = postoperative pain; A3 = advanced cancer pain; A4 = postherpetic neuralgia |
| B | Age group | B1 = adult (≥18 y); B2 = child (<18 y, precise age required) |
| R | Renal status | R1 = normal / no significant abnormality found; R2 = abnormal / uncertain → proceed to stratification; R3 = not yet checked |
| R tiers | Five values of R2 | Normal (CLcr ≥ 90) / mild (60–89) / moderate (30–59) / severe (15–29) / extreme (<15 mL/min) |
| N | NSAID screening | N-ulcer = gastroduodenal ulcer; N-ibd = inflammatory bowel disease; N-none = neither |
| U | Ulcer activity (follow-up only when N-ulcer) | U-active = active ulcer; U-history = healed (ulcer history) |
| F | Postoperative oral status (A2 only) | F1 = fasting period (NPO); F2 = oral intake resumed (PO) |
| T | Opioid tolerance (follow-up only when A3 NPO) | T-tolerant = opioid tolerant; T-naive = opioid-naïve / uncertain |
| Output markers | — | 🔴 = mandatory consult (no drugs recommended); 🟠 = recommended consult (may proceed, logged); 🟢 = recommendation printed |

## I. Global Preflow (shared by all scenarios)

```
Scene selection A → Age selection B → (child: precise age input) → Renal screening R → scenario branch
```

**Three exits of renal screening R:**

| Path | Adult | Child |
|:---|:---|:---|
| R1 normal / no significant abnormality | proceed | proceed |
| R2 abnormal → stratification | Mild/moderate: 🟠 or warning then proceed; severe/extreme: 🔴 Nephrology + Pain Medicine | **any tier (including mild): 🔴 Pediatrics + Nephrology** (Issue 103) |
| R3 not yet checked | may proceed after warning (logged) | 🔴 testing must be completed, or 🔴 Nephrology consult then specialist-directed |

## II. A1 Acute Spasmodic Pain

| Path | Decision chain | Output |
|:---|:---|:---|
| A1→B2, age <2 | R normal → N any | 🔴 mandatory Pediatrics consult |
| A1→B2 with ulcer/IBD | boundary triggered by N screening | 🔴 mandatory Pediatrics + Gastroenterology consult |
| A1→B2, age 2–11, no contraindication | R normal + N none | 🟢 dexibuprofen (first choice) / acetaminophen drops weight-based; tramadol <12 y contraindicated → 🟠 pediatric consult confirmation |
| A1→B2, age ≥12, no contraindication | same as above | 🟢 whitelist (phloroglucinol / dexibuprofen / acetaminophen; tramadol optional) → 🟠 pediatric consult confirmation |
| A1→B1 (adult), N none | — | 🟢 phloroglucinol + ketorolac combination (Issue 78); red-text warnings appended for mild renal impairment / unchecked |
| A1→B1, N ulcer/IBD | — | 🟢 antispasmodics only (NSAIDs avoided); refer to specialist consult if ineffective |

## III. A2 Postoperative Pain

Entry: N screening runs after B (if not yet done), then F (NPO/PO) is selected.

### F1 Fasting Period (NPO)

| Path | Output |
|:---|:---|
| →B2 boundary triggered (<2 y / ulcer / IBD / renal impairment) | 🔴 mandatory Pediatrics + corresponding-specialty consult |
| →B2, age 2–11, no contraindication | 🔴 mandatory pediatric consult (no usable injectable within whitelist) |
| →B2, age ≥12, no contraindication | 🟢 tramadol injection (ketorolac/indomethacin multi-dose not recommended) → 🟠 pediatric consult confirmation |
| →B1 ulcer | 🟢 ladder starts from tramadol injection (NSAIDs removed), 🔴-style warning |
| →B1 IBD | 🟢 same (🟠-style warning) |
| →B1 no contraindication, moderate/severe renal impairment | 🟢 NSAIDs avoided: tramadol 50 mg q8h + fentanyl-class agents require specialist assessment (Issues 74/86) |
| →B1 no contraindication, otherwise | 🟢 full ladder: ketorolac → indomethacin suppository → tramadol → fentanyl-class; dose-reduction warnings for mild impairment / unchecked |

### F2 Oral Intake Resumed (PO)

| Path | Output |
|:---|:---|
| →B2 boundary triggered | 🔴 mandatory consult (same as above) |
| →B2, age 2–11, no contraindication | 🟢 acetaminophen (tablets barred <6 y) + dexibuprofen weight-based; tramadol contraindicated → 🟠 pediatric consult confirmation |
| →B2, age ≥12, no contraindication | 🟢 whitelist + tramadol optional → 🟠 pediatric consult confirmation |
| →B1 ulcer | ulcer-activity follow-up: active/unknown → 🟢 NSAIDs avoided (acetaminophen + tramadol), 🔴 warning; healed → 🟢 same, celecoxib requires PPI + Gastroenterology consult |
| →B1 IBD | 🟢 NSAIDs avoided + Gastroenterology consult note |
| →B1 no contraindication, moderate/severe renal impairment | 🟢 acetaminophen first + tramadol q8h, NSAIDs avoided |
| →B1 no contraindication, otherwise | 🟢 full ladder (oral ketorolac → flurbiprofen axetil → indomethacin suppository → Saridon → tramadol) |

## IV. A3 Advanced Cancer Pain

| Path | Output |
|:---|:---|
| →B2 (child) | 🔴 mandatory consult (Pediatrics + Pain Medicine) immediately after age selection; no precise age, no renal screening (Issue 69) |
| →B1 any renal impairment (including mild) | 🔴 mandatory Pain Medicine + Nephrology consult (Issue 92); oral-status question skipped |
| →B1 normal renal → PO | pain-specialist consult suggestion → N screening → 🟢 ladder: acetaminophen → tramadol → OxyContin; NSAIDs removed for active ulcer/IBD; healed ulcer requires PPI |
| →B1 normal renal → NPO | **T opioid tolerance** asked first (Issue 72): tolerant → 🟢 Durogesic ± flurbiprofen axetil (NSAIDs removed with comorbidities); naïve/uncertain → 🔴 Durogesic contraindicated + mandatory pain-specialist consult for titration |
| (continued) advanced options | if routine regimen fails → yes → 🟠 shown after pain-specialist consult confirmation (intrathecal morphine pump / nerve block / neurolytic nerve block) |

## V. A4 Postherpetic Neuralgia

| Path | Output |
|:---|:---|
| →B2 (child) | 🔴 mandatory consult (Pediatrics + Pain Medicine) immediately after age selection (Issue 69) |
| →B1 moderate/severe/extreme renal impairment | severe/extreme already 🔴 intercepted at R; moderate → 🟢 reduced-dose table + 🟠 recommended-consult modal (Issue 93) |
| →B1 normal/mild | 🟢 gabapentin/pregabalin per renal-stratified dose table; red-text warnings for mild impairment / unchecked |

## VI. Global Constraints (cross-cutting all paths)

| Mechanism | Rule |
|:---|:---|
| Pediatric whitelist (Issue 90) | Only dexibuprofen, acetaminophen, tramadol (>12 y), and phloroglucinol (>2 y) may appear in pediatric recommendations |
| Pediatric boundary (Issues 87/88) | <2 y / ulcer / IBD / any renal impairment / cancer pain / neuralgia → always 🔴 |
| Aspirin | Contraindicated in children across all scenarios (Reye's syndrome), fixed warning |
| Pethidine (meperidine) | Enters no routine ladder (Issue 75; not recommended by WHO for cancer pain) |
| Audit trail | Consult confirmations / refusal reasons / proceeding-with-unchecked-renal actions are all written to auditLog; refusal reasons must pass Chinese-character validation (≥5 chars, deduplication, no repeated characters), with a receipt modal after submission (Issue 100) |
